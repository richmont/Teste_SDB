# Quiz de filiação a divindades

Website de entretenimento para fãs de Percy Jackson e das demais sagas de Rick Riordan. Um questionário de personalidade calcula a afinidade do participante com divindades do panteão selecionado.

O resultado representa uma identificação lúdica: não é avaliação psicológica, diagnóstico ou probabilidade científica.

## Situação inicial

- O primeiro panteão disponível será o grego.
- A estrutura deve permitir cadastrar outros panteões e múltiplos questionários.
- Perguntas, respostas e pesos definitivos serão fornecidos posteriormente.
- A tecnologia de implementação e a fórmula de afinidade ainda não foram definidas.
- A experiência deve priorizar dispositivos móveis, desempenho e padrões abertos da web, com pouco JavaScript e sem depender de frameworks como React.

## Referências literárias

Os ebooks em EPUB são materiais externos de consulta, não entregáveis do website. Não devem ser versionados nem distribuídos com o projeto. As regras de exclusão estão em `.gitignore`; análises próprias podem ser documentadas conforme as orientações em [Referências literárias](docs/regras-de-negocio.md#8-referências-literárias).
